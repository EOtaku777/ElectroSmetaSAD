# ЭлектроСмета

Сайт, который по плану квартиры считает электрику: линии, автоматы и УЗО, сечения и метраж кабеля, состав и вид щита, смету с ценами.

Стек: HTML, CSS, JavaScript (редактор плана на SVG), Python 3 + Flask, SQLite (SQL).

## Запуск

    pip install -r requirements.txt
    python app.py          # http://127.0.0.1:5000

БД `electro.db` создаётся автоматически из `schema.sql` и `seed.sql`. Сбросить: `python db.py --reset`.
Проверка расчёта: `python -m tests.test_calc`.

## Как пользоваться

1. «Загрузить пример» или нарисовать комнаты (инструмент «Комната»), задать тип комнаты справа.
2. Поставить «Электрощит», затем розетки, выключатели, точки света и приборы.
3. Задать высоту потолков, тип ввода (1 или 3 фазы), выделенную мощность.
4. «Рассчитать» → вкладки «Линии и автоматы», «Электрощит», «Смета». На плане показываются трассы кабеля.
5. В смете можно править количество, включать рекомендуемое и работы, скачать CSV или распечатать.

## Структура

    app.py            Flask: страница и API (/api/calc, /api/catalog, /api/projects)
    calc.py           движок расчёта (все допущения — константы вверху файла)
    db.py             подключение к SQLite
    schema.sql        таблицы: products, cable_sections, appliances, works, projects
    seed.sql          каталог и цены (сгенерирован tools/gen_seed.py)
    templates/, static/   интерфейс и редактор плана
    sample_project.json   пример квартиры

## Цены и каталог

Цены в `seed.sql` — ориентировочные заглушки. Чтобы использовать реальный прайс, обновите таблицу `products`
(`UPDATE products SET price = ... WHERE sku = '...'`) или поправьте `tools/gen_seed.py` и выполните `python tools/gen_seed.py && python db.py --reset`.
Новые приборы добавляются строкой в таблицу `appliances`, без правки кода.

## Что учитывает расчёт

- Группы: освещение (до 12 точек, B10, 3×1,5), розетки (до 8 точек и 14 А, B16, 3×2,5), выделенные линии под каждый мощный прибор.
- Ток по мощности и cos φ, автомат — ближайший номинал с запасом 10 %, сечение — по допустимому току меди и падению напряжения ≤ 3 %.
- Метраж: трасса от щита до потолка, по потолку «по манхэттену», спуски к точкам, запас 10 %.
- Ванная, санузел, балкон, кухонные розетки и все выделенные линии — на дифавтоматах 30 мА; остальное — под общими УЗО.
- При 3 фазах линии распределяются по фазам, плита/варочная панель — на 3 фазы.
- Щит подбирается по числу модулей с запасом не менее 20 %.

## Ограничения

Расчёт ориентировочный. Он не заменяет проект по ПУЭ/ГОСТ Р 50571, не учитывает селективность, длины по стенам реальной планировки,
скрытые препятствия, слаботочные системы и счётчик. Перед закупкой и монтажом результат должен проверить электрик.
